# 🧠 ARIA Admin Ultra

Assistente Administrativa de Elite com Inteligência Artificial Multi-Modelo.

## Funcionalidades

- 💬 **Chat IA** — Converse com IA (Grok, Gemini, Qwen)
- 📋 **Documentos** — Redação de ofícios, contratos, atas, recibos e mais com IA
- 🔍 **OCR** — Extração de texto de imagens com Tesseract.js
- 📊 **Planilha** — Edição e análise de dados com IA
- 📅 **Agenda** — Gerenciamento de eventos com alertas
- 🔀 **Fusão IA** — Combine múltiplos arquivos em um documento
- 🌐 **Tradutor** — Tradução inteligente
- 📝 **Resumidor** — Resumo, tópicos, formalização de textos
- 📝 **Notas** — Bloco de notas completo com auto-save
- 💱 **Moedas** — Conversor de moedas com cotação em tempo real
- 📊 **Dashboard** — Painel executivo com métricas e atividades
- ✍️ **Assinatura Digital** — Assine documentos com canvas
- ☁️ **Cloud Sync** — Sincronia via Firebase (opcional)
- 📥 **Exportação** — PDF, DOCX, TXT
- 📱 **PWA** — Instalável como app no celular

## Deploy

1. Faça upload dos arquivos `index.html`, `sw.js` e `manifest.json` no [Netlify Drop](https://app.netlify.com/drop)
2. Ou conecte este repositório ao Netlify para deploy contínuo

## Tecnologias

- HTML/CSS/JS puro —Sem frameworks
- Tesseract.js — OCR gratuito client-side
- Firebase Firestore — Sincronia opcional na nuvem
- html2pdf.js — Exportação PDF
- PWA — Service Worker + Manifest
